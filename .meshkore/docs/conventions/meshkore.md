# MeshKore conventions

- Spec: https://api.meshkore.com/v1/standard.md
- Public identity: `.meshkore/public/cluster.yaml`
- Secrets: `.meshkore/credentials/` and `.meshkore.local` (gitignored)
- Tasks: `.meshkore/modules/<module>/tasks/`
- Docs: `.meshkore/docs/<category>/`
- Invite URLs are out-of-band (`MESHKORE_INVITE`), never committed
