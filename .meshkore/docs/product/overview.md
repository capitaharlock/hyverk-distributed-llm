# Hyverk

Distributed network for **training and serving** open-source coding models.
This GitHub repository is a **demo / source** tree: clone it, run locally, or deploy the coordinator yourself.

MeshKore (`.meshkore/`) organizes agentic collaboration around the same repo. It is not the inference coordinator.
